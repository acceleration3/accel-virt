# The Vulkan CTS subset this repository runs in the guest (feature 048, US1).
#
# Case-name patterns, not case names: one dEQP group is thousands of cases and
# the list changes with every CTS release, so the runner asks the CTS itself
# for its case list and keeps the ones these patterns match. A pattern is a
# glob over a case name.
#
# Every extension the Vulkan ICD reports must be exercised by a pattern here
# (FR-005, constitution VI): tools/check_cts_subset.py reads the ICD's policy
# table and fails the build naming any reported extension with no group. The
# `for:` tag is what it matches on, so a new policy row without a group here is
# visible the moment it is added.
#
#   <pattern>    for: <extension> [, <extension>...]
#   <pattern>    for: core        # what every run must pass whatever is reported

dEQP-VK.api.smoke.*                             for: core
dEQP-VK.api.device_init.*                       for: core

dEQP-VK.memory.allocation.basic.*               for: core
dEQP-VK.memory.mapping.suballocation.*          for: core
