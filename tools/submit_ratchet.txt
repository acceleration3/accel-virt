# What user-mode submission bought, committed (feature 049, US3): one line,
# `ratio <hundredths>`, where 250 is a kernel submission costing two and a half
# times a doorbell one. A run whose ratio falls below it fails; a run that
# raises it writes the new line in the change that earned it -
# tools/guest/run_guest_suite.py prints the line to add.
#
# The nanoseconds either path costs are the host's property and are not kept
# here: the ratio is the driver's.
#
